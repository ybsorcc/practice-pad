# Practice Pad

A small installable web app that sits beside the daily word-grouping puzzle. Load a screenshot of the board (or paste the words), sort all 16 words into four colour groups at once, with "maybe" marks for red herrings, and then go back to the game to enter your answers.

It never replaces the game. It doesn't check answers, fetch puzzles, or use any of the game's names or styling. Everything runs on the device: the screenshot is read locally with Tesseract.js and never uploaded. There are no accounts and no analytics.

**Live:** https://ybsorcc.github.io/practice-pad/ (once GitHub Pages is turned on, see below)

## Files

| Path | What it is |
|---|---|
| `index.html`, `styles.css`, `app.js` | The app: screens, board rules, saving to the device |
| `ocr.js` | Screenshot reader: finds the tile grid, crops each tile, and runs OCR on it |
| `sw.js`, `manifest.webmanifest`, `version.js` | Install, offline and Android Share-sheet support. **Bump `version.js` on every release.** |
| `vendor/tesseract/` | Self-hosted Tesseract.js 5.1.1: worker, LSTM wasm cores and `eng` traineddata (best_int) |
| `fonts/` | Self-hosted Barlow and Barlow Condensed (SIL OFL) |
| `icons/` | App icons, generated by `dev/make-icons.js` |
| `dev/` | Test tooling only, not used by the app (see Testing) |

## Publishing (one time, in GitHub Desktop)

1. **GitHub Desktop → File → Add local repository…** and choose this `practice-pad` folder. When it says the folder isn't a repository yet, click **create a repository**. Keep the name `practice-pad`, leave the template options set to *None* (`.gitignore` and `.gitattributes` are already here), and click **Create repository**.
2. Check the changed-files list. It should **not** include `dev/node_modules` or any screenshots. Commit to `main` with the message: *Add Practice Pad v1.0.0, a phone and iPad companion for sorting the daily word groups*.
3. Click **Publish repository**. **Untick "Keep this code private"**, because Pages on a free account needs a public repo. Then click **Publish**.
4. On github.com, open the repo and go to **Settings → Pages**. Under *Build and deployment*, set Source to **Deploy from a branch**, Branch to **main**, and folder to **/ (root)**, then click **Save**. After a minute or two the site appears at `https://ybsorcc.github.io/practice-pad/`.

## Installing

- **Galaxy S20 (Chrome):** open the URL, then choose **⋮ → Add to Home screen → Install**. After that, *Practice Pad* shows up in the Gallery's **Share** sheet.
- **iPad (Safari):** open the URL, then choose **Share → Add to Home Screen**. iPadOS doesn't let web apps receive shares, so use **Load screenshot** in the app instead.
- Open the app once while online, then load one screenshot so the reader downloads (about 7 MB, one time only). After that it works in airplane mode.

## Updating

Change the files, bump `version.js`, then commit and push in GitHub Desktop. On the devices, **close the app and reopen it** while online, and the new version loads. You never need to reinstall. The version number is shown at the bottom of the start screen.

## Testing (on a PC, needs Node.js)

```bash
cd dev
npm install
npx playwright install chromium
node run-ocr-test.js     # reads every image in ../../test-screenshots and compares with dev/expected.json
node run-app-test.js     # board rules, saving, offline, share target, and layout screenshots in dev/shots/
node server.js           # serves the app at http://127.0.0.1:8765/practice-pad/
```

The test screenshots live **outside** this repo, in `../test-screenshots`, because they're the game's own content. To add a new one, drop it in that folder and add its expected words to `dev/expected.json`.
